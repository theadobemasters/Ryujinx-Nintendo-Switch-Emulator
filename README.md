# Ryujinx Nintendo Switch Emulator

**Ryujinx Nintendo Switch Emulator** is a free **nintendo switch emulator** for Windows, Linux and macOS. This **ryujinx download** is the **ryujinx canary** channel: 4K 60FPS, Vulkan, LDN, LayeredFS. You still need **ryujinx firmware** and **keys ryujinx** dumped from your own console. A common **best switch emulator** pick next to Eden on phones.

## Setup
1. **Firmware** — Tools > Install Firmware (18.x / 19.x from your dump).
2. **Keys** — prod.keys in the Ryujinx system folder.
3. **Games** — add a folder of NSP/XCI files.

## FAQ

**Ryujinx vs Yuzu?**
Yuzu stopped in 2024. Ryujinx stays the accuracy-first desktop option; Eden covers phones.

**Android / apk?**
No official **ryujinx android** build.

**Legal?**
Emulators are legal. Dump firmware, keys and games you own.

## Requirements
